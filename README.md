# Goonk Vilaivanh Portfolio

This is a React and Vite portfolio project currently being built for a client.

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deploy To GitHub Pages

```bash
npm run deploy
```

The project is configured for a custom domain on GitHub Pages. In the GitHub repository, go to **Settings > Pages**, select the `gh-pages` branch, and add the custom domain there.

If you want the custom domain to stay tracked in the project, add a `CNAME` file inside `public/` with only the domain name inside it, such as:

```txt
example.com
```
